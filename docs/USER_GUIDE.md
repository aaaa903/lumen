# Lumen 使用说明

适用版本：v0.4.0（V1 最终版本），Windows x64。

Lumen 把读书、做标记、整理笔记放在同一个窗口里。书和笔记都留在本机，不需要账号，也不联网。

这份说明按「第一次使用到长期维护」的顺序写。遇到问题时先看最后的常见问题，那里覆盖了安装被拦截、PDF 显示异常、搜索无结果这几类。

## 1. 安装

从 [GitHub Releases](https://github.com/aaaa903/lumen/releases) 下载当前版本，有两种形态：

- `Lumen-0.4.0-setup.exe`：安装版，可以自定义安装目录，会创建桌面快捷方式。
- `Lumen-0.4.0-portable.zip`：免安装包，解压到任意目录，双击 `Lumen.exe` 运行。

安装包没有代码签名，Windows 会提示「未知发布者」。如果系统开启了智能应用控制（Smart App Control），`setup.exe` 可能被直接拦截，此时改用 `portable.zip`。不要为此关闭智能应用控制——免安装包同样能正常使用，数据位置也完全相同。

卸载应用不会删除你的书、标注和笔记。要删除数据，见第 10 节。

## 2. 导入书籍

打开应用后，点右上角「导入书籍」，或者把文件直接拖进窗口。支持多选。

- 支持的格式：EPUB、PDF、Markdown（`.md` / `.markdown`）、TXT。
- 单个文件上限 200 MB。
- 导入时会把原文件复制一份到数据目录，之后移动或删除原文件都不影响书库。
- 同一个文件重复导入会提示已经存在，不会新增卡片；如果这本书之前被你移出过书库，会恢复原记录，标注和进度都还在。

导入成功后，后台会开始为这本书建立全文搜索索引。索引完成前，书架卡片上显示「未索引」，这期间可以正常阅读，只是搜索暂时搜不到这本书。

## 3. 书架

书架按最近阅读时间排序，显示封面、书名、作者和阅读进度。

- 没有封面的书，用书名首字和固定颜色生成一张卡片。- 顶部搜索框按书名或作者筛选。
- 点卡片打开这本书；卡片上的「移除」用来把书移出书库。
- 书架底部有「已移除」分组，用于恢复误移出的书，详见第 9 节。

## 4. 阅读

### 翻页与定位

- 点击页面左右区域、按方向键（左右和上下都可以）、空格、PageUp / PageDown 翻页。
- 底栏显示「第 x / y 页」和整本书的百分比，两侧是「上一章」「下一章」。
- 关闭应用再打开，会回到上次读到的位置。进度是自动保存的，不需要手动操作。

### 目录

点顶栏的目录按钮打开抽屉。目录按原书结构递归展开，当前章节高亮并自动滚动到可见位置。PDF 优先读取文件自带的书签大纲；没有大纲时按页码列出各节。

### 排版

点顶栏的排版按钮调整：

- 字号 80%–170%。
- 行距三档、页边距三档。
- 四套配色：白纸、米黄、灰绿、夜间。
- 「分页 / 滚动」开关。分页适合逐页阅读，滚动适合长文和 PDF 式浏览。

排版选择会记住并跨书生效。切到滚动模式后，翻页键一次滚一屏，到章节底部再按会进入下一章；切回分页仍停在原来的章节。

### 阅读 PDF

PDF 用单独的渲染方式，交互和 EPUB 略有不同：

- 上下滚动浏览，顶栏可以缩放 60%–220%。
- 同样支持四套配色，夜间配色会给页面反转颜色，扫描件可能显得偏暗。
- 支持目录、书签、选中文字高亮和批注。
- 不能跨页选择文字，需要分两次标注。
- PDF 不参与全文搜索，也不会出现在书内搜索里。

## 5. 标注

### 高亮与批注

选中文字后会出现浮动工具条：

- 四种颜色的高亮。
- 写批注：批注用 Markdown 编辑，可以切换预览；空批注的标注仍然算高亮。
- 复制选中的文字。

跨段落选择时，会自动拆成按段落的几条高亮，删除时整组一起处理。

### 侧栏

点顶栏的标注按钮打开侧栏，按章节列出这本书的全部标注，显示原文片段和批注摘要，点击跳到原文位置。侧栏里可以：

- 改颜色、改批注、删除。
- 勾选多条后「导出所选」，或者「导出全部」。
- 查看「引用 N / 被引 N」。

删除标注后有 5 秒的撤销窗口，点提示条上的「撤销」可以恢复。

### 书签

按 `Ctrl+B` 或点顶栏的书签按钮标记当前位置，可以写一句备注。书签和标注一起出现在侧栏，也能从侧栏跳回。PDF 的书签记录的是页码。

### 引用其他标注

在批注编辑器里可以插入「引用标注」，批注里会出现一个引用标记。预览时显示被引用标注的章节和原文片段，点击跳到目标；侧栏显示引用计数，也能看到哪些批注引用了当前这条。

如果被引用的标注后来被彻底删除，引用处会显示「引用的标注已不存在」，不会影响批注本身。

### 标注位置变化

标注同时保存位置信息和原文片段。如果书籍文件被外部工具改写、排版发生变化，打开时会按原文片段重新查找位置。重新贴合失败时，这条标注会被标记为失效，但原文和批注都会保留，不会悄悄删除。

## 6. 搜索

### 跨书搜索

点顶栏「搜索」进入搜索页，可以切换两个范围：

- 正文：在所有书里检索正文，结果按书和章节分组，命中词高亮，点击跳回原文位置。
- 标注：只搜标注原文和批注，结果带书名与章节，随时可查，不依赖索引。

正文搜索依赖索引。刚导入的书需要等「未索引」标记消失；大书可能要几十秒。中文支持两个字以上的子串匹配，英文单词也能直接命中。

### 书内搜索

在阅读器里按 `Ctrl+F` 打开书内搜索，只检索当前这本书，至少输入两个字。

结果按章节顺序列出，同一章的多处命中会分别成条。点击任一条跳到原文位置，并临时高亮约 6 秒。索引还没完成时会提示结果可能不全。PDF 不提供这个入口。

## 7. 笔记与标签

### 笔记

切到「笔记」页可以写不绑定任何书的 Markdown 笔记。

- 点「新建」开始写，编辑区支持 Markdown，`Ctrl+S` 保存。
- 可以手动关联一本书，方便日后找回出处；不关联也可以。
- 笔记保存后立即写进本地数据库，不需要额外操作。

### 标签

标签用来给标注分类，在「笔记」页左侧管理：创建、改名、删除、合并。

- 每个标签一种颜色。
- 合并会把源标签下的标注转到目标标签，标注本身不会被删除。
- 删除标签只解除关联，标注不会消失。

## 8. 导出

### 导出单本书

在阅读器侧栏点「导出全部」导出这本书的所有标注；勾选若干条后点「导出所选」只导出选中的部分。导出前可以先预览 Markdown，再决定保存文件或复制到剪贴板。

### 导出整个书库

打开设置，点「导出全部标注…」并选择一个目录。应用会在该目录下新建一个带时间戳的子目录，一本书一个 Markdown 文件，按书名命名。

- 没有标注的书不会生成空文件。
- 文件名重复时自动加序号，不会覆盖已有文件。
- 内容与单书导出一致。

导出的文件以 YAML front matter 开头，记录书名、作者、导出时间和 Lumen 版本，正文用引用块列出原文与批注。批注里的引用标记会换成「章节 + 原文片段」，可以直接在 Obsidian、Typora 等工具里打开。

## 9. 移出、恢复与彻底删除

### 移出书库

在书架卡片上点「移除」。默认选项是「移出书库，保留标注与笔记」：

- 书从书架消失，进入书架底部的「已移除」分组。
- 源文件、标注、进度和笔记全部保留。
- 重新导入同一个文件，会自动接回原记录，不产生重复卡片。

确认框里也可以选择「同时删除标注与笔记」，这个操作不可撤销。

### 恢复

展开书架底部的「已移除」，点「恢复到书架」，书会回到书架并保留原来的阅读进度。

### 彻底删除

在「已移除」里选择彻底删除，会连同这本书的标注、笔记、索引和源文件一起清掉，无法撤销，也无法通过重新导入找回。

## 10. 数据、备份与清空

### 数据位置

所有数据在 `%APPDATA%\Lumen`：

| 内容 | 位置 |
| --- | --- |
| 书籍原文件 | `books\` |
| 封面 | `covers\` |
| 数据库（标注、笔记、标签、索引、进度） | `lumen.db` |
| 迁移前的自动备份 | `backups\` |

设置里显示完整路径，可以复制路径或在资源管理器中打开。

### 备份

先退出应用，再复制整个 `%APPDATA%\Lumen` 目录。恢复时把目录放回原位置，重新启动即可。

数据库使用 WAL 模式，运行中会存在 `lumen.db-wal` 和 `lumen.db-shm`，所以备份前退出应用可以避免拿到不一致的状态。应用在升级数据库结构前会自动备份到 `backups\`，保留最近三份。

### 清空全部数据

设置里的「清空全部数据」会删除书籍、标注、笔记、标签、索引和书籍文件，不可撤销。窗口位置、日志和迁移备份会保留。清空前建议先退出应用并复制一份数据目录。

## 11. 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Esc` | 退出阅读，回到书架 |
| `Ctrl+B` | 添加书签 |
| `Ctrl+E` | 打开或关闭标注侧栏 |
| `Ctrl+F` | 打开书内搜索 |
| `Ctrl+S` | 保存正在编辑的笔记 |
| 方向键、空格、PageUp / PageDown | 翻页；滚动模式下滚动一屏 |

## 12. 隐私

Lumen 没有账号、没有云同步、没有遥测，也不检查更新。

- 主进程会拦截所有非本地网络请求，应用运行期间不会连接外部服务器。
- 版本更新只在官网或 GitHub Releases 手动下载。
- 应用内的外部链接只交给系统浏览器打开，应用本身不加载网页。

## 13. 常见问题

### 安装时提示未知发布者，或者安装包被拦下

安装包没有代码签名，属于已知现象。改用 `Lumen-<版本>-portable.zip`，解压后直接运行 `Lumen.exe`，功能与安装版完全相同。不要为了安装而关闭智能应用控制。

### 打开 PDF 是空白页，或者中文显示成方块

通常是安装不完整，缺少随应用分发的 pdf.js 字体与字符映射资源。重新下载完整的 `portable.zip` 或安装包，不要只拷贝其中的 `Lumen.exe`。

### 书架上的书一直显示「未索引」

索引在后台进行，大书需要几十秒到几分钟。可以先正常阅读。如果长时间不变，关闭应用再启动，应用会在启动时补建历史遗留的未索引书。

### 搜索中文没有结果

按顺序确认：这本书是否已经索引完成；查询词是否至少两个字；是否在正确的范围里搜索（正文和标注是两个不同的范围）。刚导入的大书需要等索引完成。

### 标注位置偏了，或者显示「失效」

说明书籍文件被外部修改过，按原文重新贴合失败了。标注的原文和批注都还在，可以跳到大致位置后重新标注。用外部工具重排书籍后出现这种情况属于预期行为。

### 导出的文件会不会覆盖旧的

不会。库导出每次新建带时间戳的子目录，单本书内重名也会自动加序号。

### 卸载后数据还在吗

在。卸载只删除程序，`%APPDATA%\Lumen` 会保留。要彻底清除，卸载后手动删除该目录，或在设置里先执行「清空全部数据」。

## 14. 已知限制

- 只支持 Windows x64，暂无 macOS 构建。
- 不支持 MOBI、AZW3、DJVU，也不处理 DRM。
- 扫描版 PDF 没有文字层，不能选中、高亮或搜索，也不做 OCR。
- PDF 不支持跨页选择，也不参与全文检索。
- 固定版式 EPUB（以图片排版的书）不受支持。
- 无账号、云同步、在线词典、AI 摘要等任何联网功能。
- 代码签名尚未接入，安装包在部分 Windows 安全策略下会被拦截，用免安装包即可。
